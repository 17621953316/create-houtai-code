# 生成 Vue 代码的格式约定

本文件描述 `src/generator/index.js` 中 Handlebars 模板产出的 **SFC 代码风格**，修改生成逻辑时请保持一致。

## 缩进

- **`<template>` / `<script>` / `<style>`** 内统一使用 **4 个空格** 缩进（与当前生成器一致）。

## Vue 模板：标签属性换行

- **每个属性独占一行**（含 `type`、`class`、`width`、`align`、`prop`、`label`、`@click`、`@change`、`v-model`、`:data` 等）。
- **例外**：纯文本子节点可紧跟在结束属性行后，例如  
  ` @click="fn">查询</el-button>`（属性已各占一行，仅文案与闭合标签同行）。
- **条件属性**（Handlebars `{{#if}}`）：`if` 块内单独一行写该属性，避免与相邻属性挤在同一行。
- **自闭合组件**：最后一个属性（或条件块）后的 `/>` 可与最后一项属性同一行，或与条件 `{{/if}}` 同一行（见 `el-cascader` 的 `:props` 条件写法）。

## 脚本与样式

- 生成脚本中字符串字面量优先使用 **单引号**。
- 颜色等避免歧义的 RGBA 写法见生成器内既有约定（如表头 `rgba(0, 0, 0, 0.65)`）。

## 维护说明

调整生成结果格式时，请同步更新本文件与 `getTemplateSource()` 中的模板字符串。
